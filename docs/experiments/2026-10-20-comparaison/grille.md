# Grille d'évaluation — quatre lectures, noms neutres

Quatre dossiers (W, X, Y, Z) traitent le **même thème fictif** avec le **même modèle**.
Ils ne diffèrent que par le dispositif éditorial qui a préparé le travail du rédacteur.
La correspondance entre les lettres et les versions est dans un fichier séparé :
`_correspondance-privee.json` — **à n'ouvrir qu'après avoir noté**.

## Comment noter

Pour chaque texte, mettez une note de 1 (faible) à 5 (excellent), et **une phrase de justification**
avec un exemple précis (citation courte). Une note sans exemple ne compte pas.

| Critère | W | X | Y | Z |
|---|---|---|---|---|
| **Profondeur** — interprétation croisée, pas une succession de descriptions | | | | |
| **Croisements justifiés** — les liens entre configurations sont-ils fondés sur les faits ? | | | | |
| **Personnalisation** — ce texte pourrait-il décrire n'importe qui ? (5 = non) | | | | |
| **Fluidité** — le texte se lit-il sans effort ? | | | | |
| **Non-répétition** — chaque chapitre apporte-t-il quelque chose de distinct ? | | | | |
| **Intérêt pour le lecteur** — envie de poursuivre ? | | | | |
| **Traçabilité** — peut-on relier chaque affirmation aux faits du thème ? | | | | |

## Questions ouvertes (réponse libre, par texte)

1. Quel passage vous a le plus appris quelque chose sur ce thème fictif ?
2. Quel passage vous a paru générique ou interchangible ?
3. Le troisième chapitre (« aspects majeurs ») apporte-t-il une idée absente des deux premiers ?
4. Si vous deviez en livrer un seul à un client, lequel, et pourquoi ?

## Rappel

Quatre textes ne permettent pas d'établir une supériorité statistique. Cette comparaison est
**exploratoire** : elle sert à décider si le dispositif éditorial change quelque chose de visible,
pas à produire un classement définitif.
