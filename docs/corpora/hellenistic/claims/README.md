# Hellenistic Documentary Claims

This folder stores `DocumentaryClaim` inventories for the initial Hellenistic corpora.

The folder is intentionally split by corpus:

- [Valens](valens.md)
- [Dorotheus of Sidon](dorotheus.md)
- [Ptolemy](ptolemy.md)
- [Comparisons](comparisons.md)

Claims in this folder are documentary records only. They are not production rules.

Current verified claim count:

- Valens: 4
- Dorotheus: 4
- Ptolemy: 5

Extraction remains limited to passages directly accessible through working digital sources. No claim is a production `RuleVersion`.

Comparison records do not merge corpus claims into common rules.
