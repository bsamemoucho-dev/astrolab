# Hellenistic Knowledge Sources

This register records selected bibliographic sources for the initial Hellenistic corpus work.

These records are documentation sources only. They do not validate any production `RuleVersion`, and they do not make any edition, primary source, or translation automatically true.

## Access Status

The following reference editions have been selected bibliographically, but their full texts are not available in the local project environment.

No source passage has been verified from these editions in this repository.

## Translations Retained

Translations retained as working layers:

- `ks-valens-riley-skyscript`
- `ks-ptolemy-robbins-lacuscurtius`
- `ks-dorotheus-pingree-book1-skyscript`

Dependency rule:

- translations are never independent confirmations of the texts they translate;
- translated claims must preserve their source dependency and transmission layer;
- passage-level extraction must mark whether the claim comes from Greek text, Arabic transmission, translation, reconstruction, or secondary interpretation.

When translations are added, each translation must receive its own `KnowledgeSource` id and must declare `dependsOnSourceIds` pointing to the source text or edition it translates when applicable.

Translations must not be counted as independent confirmations of the text they translate.
