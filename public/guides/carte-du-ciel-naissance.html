Carte du ciel

Comment lire une carte du ciel de naissance ?

Une carte du ciel peut impressionner : symboles, degrés, lignes, maisons. Pour la rendre lisible, il faut la prendre par couches plutôt que chercher une phrase définitive.

Première couche : les planètes

Chaque planète représente une fonction symbolique : vitalité, émotion, parole, désir, action, structure, expansion. Les signes indiquent la couleur ou le style de cette fonction.

Deuxième couche : les maisons

Les maisons situent les thèmes dans des domaines de vie. Elles dépendent fortement de l'heure de naissance, donc elles doivent être traitées avec prudence si l'heure est incertaine.

Troisième couche : les aspects

Les aspects relient les planètes. Ils montrent où le thème est fluide, tendu, concentré ou stimulant. C'est souvent là que la lecture devient vraiment personnelle.
